# Getting help

- **Questions, ideas, "how do I…"** — GitHub Discussions.
- **Bugs** — GitHub Issues, with the bug template: version, configuration
  (single node or cluster, object store), steps to reproduce, logs.
- **Security problems** — privately, as described in [`SECURITY.md`](SECURITY.md).
- **Commercial licensing or a hosted offering** — see [`LICENSING.md`](LICENSING.md).

Start with the docs: [`README.md`](README.md), [`docs/quickstart.md`](docs/quickstart.md),
[`docs/self-hosting.md`](docs/self-hosting.md), the operational runbooks in
[`docs/runbooks/`](docs/runbooks/) and the architecture overview in
[`docs/architecture.md`](docs/architecture.md).

Support is best effort from the maintainers and the community; there is no
service-level agreement for the source-available release.
